새로운 서비스 추가 방법

포트폴리오에 새로운 사이트나 서비스를 추가하려면, data/projects.js 파일의 PROJECTS 배열에 아래 형식의 객체를 하나 추가하기만 하면 됩니다. 

{
  id: 'my-service',
  slug: 'my-service',
  title: '서비스명',
  titleEn: 'My Service',
  category: 'travel', // travel | culture | mobility | tools | lifestyle
  categoryLabel: '여행 & 아웃도어',
  status: 'live',
  statusLabel: '운영 중',
  badge: '대표 특징 뱃지',
  accentColor: '#3b82f6',
  gradient: 'linear-gradient(135deg, #2563eb 0%, #38bdf8 100%)',
  summary: '한 줄 소개글',
  description: `상세 소개 및 개발 배경`,
  highlights: [
    { title: '핵심 장점 1', desc: '상세 설명' },
    { title: '핵심 장점 2', desc: '상세 설명' }
  ],
  techStack: ['React', 'Next.js', 'Tailwind CSS'],
  url: 'https://...',
  githubUrl: 'https://github.com/pyw31337/...'
}

자세한 가이드는 프로젝트 루트의 ADDING_PROJECT.md 문서를 참고해주세요.
